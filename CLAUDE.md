# Agent Instructions

Before changing code, read:

- `docs/PROJECT_CONTEXT.md`
- `docs/AI_HANDOFF.md`

Rules for future coding agents:

- Make narrow, explicitly approved changes only.
- Preserve unrelated sections and existing functionality.
- Avoid horizontal overflow and prioritize mobile usability.
- Never add duplicate floating, fixed, sticky, or scroll-triggered controls.
- Avoid installing dependencies unless genuinely necessary.
- Preserve approved business information, prices, SEO, and contact details.
- Run lint and production build validation after implementation.
- Update `docs/AI_HANDOFF.md` before completing every task.
- Never delete assets solely because they appear unused without approval.
